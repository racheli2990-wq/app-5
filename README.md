# HELEN — Personal Android Assistant

A Hebrew-first Android assistant with voice input, app/device shortcuts, accessibility-assisted screen actions, reminders, notes, tasks, expense and water tracking, routines, local knowledge import and backup/restore.

Some system actions require explicit Android permissions or confirmation. Transit queries hand off to an installed maps/transit app and require connectivity. See the app screens for permission explanations.

Build the debug APK using GitHub Actions (`.github/workflows/android.yml`).
